# Customer-query-classification
#Overview
This project classifies customer messages into one of nine e-commerce support categories.
#Classification Rules
1. Read the customer query and identify its main intention.
2. Choose the single most appropriate category.
3. Output only the category name.
4. Do not include explanations, punctuation, or extra text.
5. 
Example
Input: My order has not arrived yet.
Output: Delivery
